# Support API Academy

Trilha técnica de APIs e Integrações do Suporte C2S.

Portal de referência para o time de suporte investigar e testar a API de integração do C2S: procedimentos organizados por módulo, vídeos demonstrativos e exemplos prontos para uso.

## Tecnologia

Site estático (HTML, CSS e JavaScript puro, sem dependências de build).

## Rodando localmente

Basta abrir o `index.html` em um navegador, ou servir a pasta com qualquer servidor estático:

```
npx serve .
```
